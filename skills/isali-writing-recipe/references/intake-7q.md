# 7 问预检

动笔前必答 7 题。**每题都要有具体答案**，含糊（"大概"/"差不多"/"应该是"）等于没答 → 退回补素材，不动笔。

---

## Q1. 文章类型

**问**：这篇属于以下哪一类？

| 类型 | 特征 | 例 |
|---|---|---|
| 信息差 | 别人不知道的事实 / 资源 / 工具 | "这个 API 不限速但没人在用" |
| 痛点解决 | 教读者解决一个具体问题 | "为什么你的 AI 写不出好文章" |
| 反思感悟 | 个人经历提炼出的认知 | "做产品 3 年，我学到的最反直觉的事" |
| 评测对比 | 横向对比给购买/选择决策 | "Claude vs GPT 跑 5 个 task 谁赢" |
| 资讯解读 | 一个热点 + 你的视角 | "OpenAI 发布 X，真正值得注意的是 Y" |
| meta 方法论 | 教读者怎么思考/工作 | "我是怎么做信息源筛选的" |
| 故事叙事 | 情节驱动 + 收束在洞察 | "那年我差点辞职，后来…" |

**为什么问**：类型决定 recipe 候选集——不同类型不能混用同一种结构。
**没答案怎么办**：选不出来 → 选题本身没想清楚，回到选题阶段。

---

## Q2. 核心判断

**问**：用一句话讲清楚这篇文章要让读者带走什么观点？

**硬约束**：
- ≤ 30 字
- 必须是判断句，不是名词性短语（错：×"关于 AI 写作"；对：√"AI 写作的关键是配方而不是模型"）
- 把这句话单独拎出来读一遍，朋友能听懂吗？听不懂 = 没拆透

**为什么问**：核心判断决定文章的"轴"——所有素材、推进、收尾都要服务这一句。讲不清 = 不能动笔。
**没答案怎么办**：素材还没消化完，回去多读 / 多想，**不能"边写边想清楚"**。

---

## Q3. 目标读者

**问**：这篇文章给"哪一类具体的人"看？

**硬约束**：
- 必须能脑补出**一个具体的人**（年龄、职业、当前在做什么）
- 不接受"对 X 感兴趣的人"这种泛抽象
  - 错：×"对 AI 写作感兴趣的人"
  - 对：√"工作 3-5 年、写公众号但还没找到自己声音的产品/运营从业者"

**为什么问**：读者画像决定钩子和语言。读者不清晰 → 写出来谁都不爱看。
**没答案怎么办**：先去看 3 个你想象中的读者（朋友 / 同事 / 评论区某个 ID），具体到名字。

---

## Q4. 开头钩子类型

**问**：开头 100 字让读者**认领**什么？

可选：
- **场景认领**：描述一个常见现象，读者觉得"这就是我"（推荐：痛点解决 / 反思感悟）
- **悬念抛出**：一个反直觉的事实 / 数据，读者想知道答案（推荐：信息差 / 资讯解读）
- **故事开场**：一个具体场景的 in-medias-res（推荐：故事叙事）
- **反问引入**：一个让读者必须回答的问题（推荐：meta 方法论）
- **数据冲击**：一组对比数据让读者警觉（推荐：评测对比）

**为什么问**：钩子类型必须跟 Q1 类型匹配——错配 = 读者前 3 段就划走。
**没答案怎么办**：回去看 Q3 读者画像——开头是写给那个具体的人看的。

---

## Q5. 结尾落点

**问**：最后 100 字要让读者**做什么 / 想什么**？

可选：
- **行动召唤**：明确告诉读者下一步做什么（推荐：痛点解决 / meta 方法论）
- **抛球开放**：抛一个问题给读者，留互动空间（推荐：反思感悟）
- **金句收束**：一句话总结全文判断，可截图（推荐：所有类型，但要确保金句够硬）
- **反问余韵**：用反问让读者带着思考离场（推荐：资讯解读）
- **数据钉死**：用一组数据把判断焊死（推荐：评测对比）

**为什么问**：很多文章前 80% 都好，结尾"综上所述"自毁——结尾是读者最后一秒的记忆点。
**没答案怎么办**：先想清楚 Q2 核心判断，结尾就是核心判断的"具体化执行指令"。

---

## Q6. 情绪模板

**问**：全文情绪走向是哪一种？

可选：
- **平稳递进**：从头到尾理性平静，靠论证密度推进（推荐：meta 方法论 / 评测对比）
- **共鸣→认知**：开头共情吐槽，中段冷静拆解，结尾提认知（推荐：痛点解决）
- **起伏波澜**：高低交替，有张有弛（推荐：故事叙事）
- **冷→热**：开头克制，逐步加温，结尾爆发（推荐：反思感悟）
- **一直冷静**：全程不带情绪，只摆事实和判断（推荐：信息差 / 资讯解读）
- **微高潮俏皮**：整体冷静，结尾允许一处俏皮（诺鸭风）

**为什么问**：情绪模板跟文风 profile 配合——选错模板会跟 profile 打架（例：用 profile=诺鸭 + 模板=起伏波澜 → 出戏）。
**没答案怎么办**：看 Q1 类型的推荐项；不确定就选"平稳递进"兜底。

---

## Q7. 争议级别

**问**：这篇的核心判断（Q2）放在公开场合，会有人反对吗？

| 级别 | 描述 | 例 |
|---|---|---|
| **L0** | 共识，没人反对 | "好文章需要有自己的观点" |
| **L1** | 边界共识，圈内人懂、圈外可能反对 | "AI 写作不是省时间是把认知显性化" |
| **L2** | 反共识，会有人激烈反对 | "大部分公众号的 AI 写作教程都在浪费时间" |

**硬约束**：
- L0 文章天花板低（没争议 = 没传播力），但风险也低
- L1 是甜蜜区——大部分爆文在 L1
- L2 要确认你扛得住反驳，且数据/事例够硬

**为什么问**：争议级别决定**是否要先做反驳预案**。L2 文章不准备反驳预案 → 评论区翻车。
**没答案怎么办**：把核心判断发给 3 个不同立场的朋友看，记录他们第一反应。
