# Disclaimer

本 skill 通过 browser-relay 驱动用户本地 Chrome，从渲染后的 DOM 抽取内容。它不使用站点官方 API，也不保证长期稳定。

## 风险

- 站点 DOM 改版会导致 adapter 失效。
- 自动化导航/抽取可能触发站点风控。
- 页面懒加载、折叠正文、登录墙、验证码会让结果不完整。
- 抽取结果需要人工复核，不能默认等同原文。

## 边界

- 不抽 cookie。
- 不逆向私有接口。
- 不绕过登录、付费墙、验证码或权限控制。
- 不承诺媒体下载；当前只保留页面中可见的图片 URL / poster URL。

## 使用建议

优先用于：

- 自己有权限访问的网页。
- 公开公众号文章。
- 需要把浏览器里可见内容整理为 markdown 的临时资料沉淀。

不建议用于：

- 大规模批量抓取。
- 权限不清楚的内容。
- 对完整性要求极高、但页面依赖复杂交互的内容。
