# 事实核查报告格式

```markdown
## 事实核查报告

### ✅ 已验证（n 条）
- "<声明原文>" [来源](URL) 一手/二手/三手
- ...

### ⚠️ 待补证（m 条）
- "<声明原文>" — 只在 <三手源> 见到，没找到原始来源
- ...

### 🚨 冲突（k 条）
- "<A 声称 X>" vs "<B 声称 Y>"
  - A 的来源：[link]
  - B 的来源：[link]
  - 建议采信：A（理由：…）

### 📊 统计
- 原文声明总数：N
- 已验证：n（占 n/N）
- 待补证：m
- 冲突：k
```

## 使用建议

- 给用户看原文的可信度速览：`n/N` 比例
- 用户能直接看到待改点（⚠️）
- 复制报告到文章 PR 里作为核查记录
